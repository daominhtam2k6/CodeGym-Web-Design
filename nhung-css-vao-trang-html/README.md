# Bài tập - Nhúng CSS vào trang HTML

## Mục tiêu

Luyện tập ba cách nhúng CSS vào HTML:

1. Inline CSS
2. Internal CSS
3. External CSS

## Phần 1 - Inline Style

File:

inline-style.html

CSS được viết trực tiếp trong thuộc tính `style` của thẻ HTML.

Ví dụ:

style="color: green;"

và:

style="color: blue;"

## Phần 2 - Internal Style

File:

internal-style.html

CSS được đặt trong thẻ `<style>` nằm bên trong `<head>`.

Các selector được sử dụng:

- h1
- p

## Phần 3 - External Style

Files:

external-style.html

style.css

HTML liên kết tới file CSS bên ngoài bằng:

<link rel="stylesheet" href="style.css">

## Kết quả

Cả ba cách đều tạo một trang gồm:

- một tiêu đề h1 màu xanh lá;
- một đoạn văn p màu xanh dương.
