# Thực hành - Sử dụng Bootstrap xây dựng form login

## Mục tiêu

Luyện tập sử dụng Bootstrap để xây dựng giao diện form đăng nhập.

## Bootstrap

Trang sử dụng Bootstrap 5 thông qua CDN.

Bootstrap CSS:

https://cdn.jsdelivr.net/npm/bootstrap@5.0.0-beta2/dist/css/bootstrap.min.css

Bootstrap JavaScript:

https://cdn.jsdelivr.net/npm/bootstrap@5.0.0-beta2/dist/js/bootstrap.bundle.min.js

## Form đăng nhập

Form sử dụng class:

form-signin

Các thành phần bao gồm:

- Bootstrap icon
- Tiêu đề Please sign in
- Email input
- Password input
- Remember me checkbox
- Sign in button
- Copyright

## Bootstrap Classes

Các class Bootstrap chính được sử dụng:

- text-center
- mb-4
- h3
- mb-3
- form-control
- checkbox
- btn
- btn-lg
- btn-primary
- btn-block
- w-100
- mt-5
- text-muted

## CSS

styles.css định dạng form ở giữa màn hình.

Form có:

width: 100%

max-width: 330px

padding: 15px

margin: 0 auto

Body sử dụng Flexbox:

display: flex

align-items: center

justify-content: center

## Input Email

Email được bỏ bo tròn ở hai góc dưới để nối liền với password input.

## Input Password

Password được bỏ bo tròn ở hai góc trên.
