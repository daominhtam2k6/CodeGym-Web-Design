# Bài tập - Tạo gallery đơn giản sử dụng Bootstrap

## Mục tiêu

Luyện tập Bootstrap Grid System và các class tiện ích để tạo Gallery responsive.

## Bootstrap

Trang sử dụng Bootstrap thông qua CDN.

## Cấu trúc Grid

Gallery sử dụng:

container

row

col-12

col-sm-6

col-lg-3

## Mobile

Class:

col-12

Mỗi ảnh chiếm 12 trên 12 cột.

Kết quả:

1 ảnh trên một dòng.

## Tablet

Class:

col-sm-6

Mỗi ảnh chiếm 6 trên 12 cột.

Kết quả:

2 ảnh trên một dòng.

## Desktop

Class:

col-lg-3

Mỗi ảnh chiếm 3 trên 12 cột.

Kết quả:

4 ảnh trên một dòng.

## Class Bootstrap bổ sung

Trang còn sử dụng:

- py-5
- mb-5
- text-center
- text-secondary
- fw-bold
- g-4
- h-100
- img-fluid
- h5
- mt-5

## Responsive

Không cần tự viết Media Query để chia cột Gallery.

Bootstrap tự thay đổi số cột theo breakpoint của Grid System.
