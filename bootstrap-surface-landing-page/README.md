# Bài tập - Xây dựng Landing Page

## Mục tiêu

Luyện tập sử dụng các thành phần Bootstrap để xây dựng một Landing Page responsive.

Trang được thiết kế dựa trên phong cách Landing Page của Microsoft Surface.

## Công nghệ

- HTML5
- Bootstrap 5
- CSS
- Bootstrap Grid System
- Bootstrap responsive utilities

## Bootstrap Components

Trang sử dụng:

- navbar
- navbar-expand-lg
- navbar-toggler
- collapse
- container
- container-fluid
- row
- col
- card
- badge
- button
- utility classes
- spacing utilities
- typography utilities
- responsive display
- responsive grid

## Hero

Hero sử dụng Bootstrap Grid:

- col-12
- col-lg-5
- col-lg-7

Trên mobile hai phần xếp dọc.

Trên desktop nội dung và ảnh hiển thị thành hai cột.

## Product Grid

Danh sách Surface sử dụng:

col-12 col-md-6 col-lg-4

Mobile:

1 sản phẩm trên một dòng.

Tablet:

2 sản phẩm trên một dòng.

Desktop:

3 sản phẩm trên một dòng.

## Responsive Navbar

Navbar sử dụng:

navbar-expand-lg

Trên màn hình nhỏ Bootstrap tự chuyển menu sang nút hamburger.

## CSS tự viết

CSS bổ sung được hạn chế.

CSS chỉ xử lý chủ yếu:

- kích thước ảnh Hero
- kích thước ảnh Product
- object-fit
- hiệu ứng hover nhẹ

Phần layout, responsive, spacing, button, navbar và card chủ yếu sử dụng Bootstrap.

## Hình ảnh

Hình ảnh được tải từ tài nguyên hình ảnh công khai của trang Microsoft Surface để phục vụ bài thực hành giao diện.

Các ảnh gồm:

- Surface hero
- Surface Pro
- Surface Laptop
- Surface Laptop Ultra
- Surface Mouse
