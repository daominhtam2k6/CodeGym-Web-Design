# Bài tập - Định dạng văn bản với CSS

## Mục tiêu

Luyện tập các thuộc tính CSS dùng để định dạng văn bản.

## Các thuộc tính đã sử dụng

### font-style

Dùng để tạo chữ nghiêng.

Ví dụ:

font-style: italic;

### text-align

Dùng để căn chỉnh văn bản.

Bài sử dụng:

- center
- justify

### font-size

Dùng để thay đổi kích thước chữ.

Ví dụ:

font-size: 18px;

### text-indent

Dùng để thụt đầu dòng của đoạn văn.

Ví dụ:

text-indent: 50px;

### color

Dùng để thay đổi màu văn bản.

Ví dụ:

color: #0000ff;

### font-family

Dùng để lựa chọn phông chữ.

### font-weight

Dùng để thay đổi độ đậm của chữ.

### line-height

Dùng để thay đổi khoảng cách giữa các dòng.

## File bài làm

- index.html
- style.css

## Kết quả

Trang HTML bao gồm:

- tiêu đề được căn giữa;
- phần mô tả được in nghiêng;
- các đoạn văn được căn đều;
- dòng đầu của đoạn văn được thụt vào;
- một số nội dung được tô màu xanh;
- chữ có nhiều kích thước và kiểu định dạng khác nhau.
